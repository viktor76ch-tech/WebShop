Конспект: Query Builder и Eloquent в Laravel

1. Query Builder

Query Builder — это построитель SQL-запросов в Laravel. Работает через фасад DB и позволяет
строить запросы цепочкой методов.

Особенности:

Работает на уровне таблиц и SQL-запросов.

Не требует создания моделей.

Возвращает обычно stdClass или коллекцию stdClass.

Поддерживает select, where, join, groupBy, orderBy, insert, update, delete, raw и т.д.

Использует PDO и prepared statements, поэтому при правильном использовании защищает от SQL-инъекций.

Пример:

php
use Illuminate\Support\Facades\DB;

$users = DB::table('users')
    ->select('id', 'name', 'email')
    ->where('active', 1)
    ->orderBy('name')
    ->get();

Вставка:

php
DB::table('users')->insert([
    'name' => 'Иван',
    'email' => 'ivan@example.com',
]);

Обновление:

php
DB::table('users')
    ->where('id', 1)
    ->update(['active' => 0]);

2. Eloquent

Eloquent — это ORM Laravel, реализующий паттерн ActiveRecord. Каждая таблица обычно имеет свою модель,
а каждая строка таблицы представляется объектом модели.

Особенности:

Работает на уровне моделей и объектов.

Требует создания моделей, например User, Post.

Возвращает объекты моделей или коллекции моделей.

Поддерживает связи: hasOne, hasMany, belongsTo, belongsToMany, morphTo и др.

Есть события модели: creating, created, updating, updated, deleting, deleted.

Автоматически управляет created_at и updated_at, если включены timestamps.

Поддерживает аксессоры, мутаторы, касты, скоупы, soft deletes.

Под капотом Eloquent использует Query Builder.

Пример модели:

php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class User extends Model
{
    protected $fillable = ['name', 'email', 'active'];

    public function posts()
    {
        return $this->hasMany(Post::class);
    }
}

Пример запроса:

php
use App\Models\User;

$users = User::where('active', 1)
    ->orderBy('name')
    ->get();

foreach ($users as $user) {
    echo $user->name;
}
Работа со связями:

php
$user = User::find(1);

foreach ($user->posts as $post) {
    echo $post->title;
}

3. Главные различия

Критерий	            Query Builder	                Eloquent
------------------------------------------------------------------------------------------------------
Уровень	                SQL / таблицы	                ORM / объекты
Модели	                Не нужны	                    Нужны
Возвращает	            stdClass,                       Модели, коллекцию моделей
                        коллекцию stdClass
Связи	                Только через join вручную	    Встроенные связи
События	                Нет	                            Есть события модели
Timestamps	            Нужно управлять вручную	        Автоматически
Аксессоры/мутаторы	    Нет	                            Есть
Касты	                Нет	                            Есть
Скоупы	                Нет	                            Есть локальные и глобальные
Soft Deletes	        Нужно реализовывать вручную     Есть через трейт
Производительность	    Обычно быстрее и легче	        Может быть медленнее из-за гидратации моделей
Удобство	            Хорош для сложных SQL	        Хорош для бизнес-логики и CRUD

4. Что общего

Оба используют PDO и prepared statements.

Оба поддерживают большинство методов построения запросов: where, orderBy, limit, join и т.д.

Eloquent внутри использует Query Builder.

В Eloquent можно применять методы Query Builder, например:

php
User::where('active', 1)->update(['last_login' => now()]);
________________________________________________________________________________________________________

5. Когда использовать Query Builder

Сложные аналитические запросы.

Отчёты с join, groupBy, union, подзапросами.

Массовые insert, update, delete.

Импорт/экспорт данных.

Когда модели не нужны и важна производительность.
________________________________________________________________________________________________________

6. Когда использовать Eloquent

Обычный CRUD.

Работа со связями между таблицами.

Бизнес-логика приложения.

События модели, аксессоры, мутаторы, касты.

API, админки, типовые задачи Laravel.

________________________________________________________________________________________________________

7. Пример одной и той же задачи
Query Builder:

php
$users = DB::table('users')
    ->join('posts', 'users.id', '=', 'posts.user_id')
    ->where('users.active', 1)
    ->select('users.name', DB::raw('COUNT(posts.id) as posts_count'))
    ->groupBy('users.name')
    ->get();
Eloquent:

php
$users = User::withCount('posts')
    ->where('active', 1)
    ->get();

foreach ($users as $user) {
    echo $user->name . ': ' . $user->posts_count;
}

Вывод

Query Builder — это низкоуровневый и более быстрый инструмент для построения SQL-запросов.
Eloquent — это высокоуровневая ORM-надстройка над Query Builder, которая делает код удобнее за счёт моделей,
связей, событий и других возможностей.

Это не конкуренты, а инструменты разных уровней. В реальном проекте их часто комбинируют:
Eloquent — для бизнес-логики и связей, Query Builder — для сложных и тяжёлых запросов.
